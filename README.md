# SSE Bank - UI/UX & Frontend Development Concept

## ⚠️ Disclaimer
**This is a student portfolio project for educational and demonstration purposes only.** 
This website is not a real financial institution, does not provide banking services, and does not collect or store real user credentials. It was created to showcase UI/UX design and frontend engineering skills.

---

## 🚀 Project Overview
**SSE Bank** is a modern, borderless financial hub concept designed to provide powerful payment solutions for digital entrepreneurs. This project focuses on high-fidelity interface design, user session management, and real-time communication features.

## 🛠️ Technical Stack
* **Design:** Figma
* **Frontend:** HTML5, JavaScript
* **Styling:** Tailwind CSS
* **Deployment:** Vercel

## ✨ Key Features
* **Live Chat Integration:** Real-time customer support widget.
* **Session Management:** Secure logout logic and user session handling.
* **Responsive UI:** Fully optimized for mobile and desktop screens.
